2026-10-26 기준 · 김규빈 정리

## 한 줄 요약

답이 나와야 하는 한국어 질문 32개 중 실제로 답한 개수가 **10개 → 30개**로 늘었다.
검증을 느슨하게 한 것이 아니라, **맞는 답을 틀렸다고 막던 오탐을 하나씩 찾아 고친 결과**다.
보류해야 하는 질문 5개(비상·법률 판단 요청)는 처음부터 끝까지 모두 보류됐다.

## 평가 방법

- 평가셋: `rag-service/eval/questions.json` 중 한국어 37문항 (답변 기대 32 · 보류 기대 5)
- 실행: `eval/answer_eval.py` (결과는 `eval/results/r1~r13.txt`, `answer_cmp-*.json`)
- 판정: 기대대로 답했는지 / 보류했는지, 보류했다면 이유(근거 불일치·번역 검사·제품 확인 등)
- 같은 질문도 검증 LLM 판정이 매번 조금씩 달라, 한 단계에서 2회 이상 돌려 범위로 기록했다.

## 단계별 상세

### 1. 모델 교체와 근거 검증 오탐 (10 → 18~23)

- 기본 LLM을 gpt-6-luna로 변경 (`llm.DEFAULT_MODEL` 한 곳에서 관리)
- 인용 비교에서 PDF 줄바꿈·공백 차이 무시 (단어 중간 줄바꿈 포함, 숫자 경계는 유지)
- MSDS 제품명이 "제품명 :" 다음 줄에 있어도 인식
- "작업을 멈추고 대피해도 되나요?"를 작업 승인 요청으로 잘못 판단하던 문제 수정
- 의무 문구가 없는 법령 인용은 일반 정보로 낮춤
- 프롬프트: 인용은 한 문장, 숫자는 원문 표기 그대로, "의무"는 의무 문구를 인용할 때만

### 2. 원문 왜곡 방지와 번역 검사 (→ 20~25)

- 프롬프트: 원문 강도 유지("하여야 한다"를 "바람직하다"로 약하게 바꾸기 금지), 법조문의 주체·처벌 종류·금액 보존
- 제품 확인: LLM이 제품을 못 뽑으면 서버가 MSDS 1·3·16항에서 직접 뽑은 값으로 다시 확인
- 번역 검사: 금액 단위(10억원)와 괄호 속 한국어 용어 병기는 문자 검사에서 허용
- `tests/test_generation_fixes.py` 추가, 답변 평가 스크립트를 저장소로 이동

### 3. MSDS 표 항목 (→ 25)

- 물성·운송·규제·약어 표(9·14·15·16항)는 문장 끝이 없어 "잘린 경고"로 판정돼 답이 막혔음
- 이 항목들을 잘림 판정에서 제외 → 잘림 청크 86개 → 28개 (전체 267개 중)
- IPA 인화점, 아세톤 개정일 같은 질문에 답할 수 있게 됨
- 경고 문장이 있는 항목(2·4·7·8·10항 등)은 그대로 검사

### 4. 법령·지침 문체 (→ 29~30)

- 법령 "다음 각 호" 목록만 인용한 의무 문장에, 같은 조문의 "~하여야 한다" 본문을 서버가 인용으로 덧붙임
- 인용 비교에서 한자 병기 "과(科)한다" 무시, 처벌 조항은 일반 정보로
- 지침의 요구 문체 인정: "이루어져야 한다", "(5) …착용한다.", "착용을 해야"
- KOSHA 쪽번호·머리글 사이에 빈 줄이 있어도 꼬리말로 인식
- 동의어: 옮겨 담·소분 → 안전취급요령

### 5. 재시도와 경고 정리 (→ 30)

- 검증 실패 시 1회 재생성
- 출처 머리글의 문서·조항 번호(K-1-2023, 7.2)를 수치 검사에서 허용
- 답변 경고를 질문 관련 항목만으로 축소: 인용한 MSDS 항목 + 2항 유해·위험 문구(H코드)만
  - 황산 약액 교체 보호구 질문: 경고 10개 → 1개
- 동의어: 이송·희석 → 안전취급요령, 보호구 → 노출방지 및 개인보호구 (검색 hit@5 97% → 100%)

## 환각 점검 (10/26)

일반 질문 8개 + 함정 질문 9개를 돌려 답변 문장을 인용 원문과 하나씩 대조했다.

- 지어낸 내용은 찾지 못했다 (표본이 작아 없다고 보장하지는 않음).
- 자료에 없는 물질(톨루엔)·없는 항목(황산 MSDS 17항)·없는 정보(과산화수소 유통기한)는 모두 보류.
- 수치(메탄올 인화점 9.7 °C, 불산 TWA 0.5 ppm, 암모니아수 보관 2~8 °C, 중대재해처벌법 벌금 상한)는 원문과 일치.
- 아쉬운 점: 수치 뒤 측정 조건("(10 hPa), 밀폐식 컵") 누락, 인용하지 않은 법 조항 해석 1건.

## 남은 문제

- 같은 질문도 검증 LLM 판정이 달라 37문항 중 33~35문항 사이에서 오간다.
- 외국어 48문항 중 7문항이 아직 보류된다 (M-C20 3개 언어, 크메르어 근거 형식 2건 등). 한국어 37문항은 최근 35/37.
- 수치 뒤 측정 조건이 빠지지 않게 하는 규칙 추가 필요.
- 응답 시간: 한국어 평균 약 10초, 외국어 약 20초 (교재 목표 3~5초). 검증 LLM·번역 검사 때문이며 병렬화·자주 묻는 질문 저장이 개선 방향.
