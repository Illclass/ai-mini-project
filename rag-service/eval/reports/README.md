# 검색 평가 보고서 (발표·비교용)

`python -m eval.run_eval` 이 실행할 때마다 만드는 결과는 `eval/results/`(git 제외)에 쌓인다.
그중 발표·비교에 쓸 것만 여기에 이름을 붙여 복사한다.

| 파일 | 날짜 | 내용 | hit@5 |
|---|---|---|---|
| `01_기준점_ada002.md` | 10/23 11:32 | 처음 인덱스(ada-002), 60문항. 번역 없음/있음 | 56% / 80% |
| `02_임베딩_4종_비교.md` | 10/23 11:39 | ada-002 · 3-small · 3-large · bge-m3 × 번역 없음/있음 → **bge-m3 선택 근거** | bge-m3 + 번역 98% |
| `03_제품범위_검색개선.md` | 10/23 15:14 | bge-m3, 70문항. 물질명 제품 자동 지정 · 잘린 MSDS 청크 제외 · 제품 범위 검색 | 96% |
| `04_동의어_순위병합_번역확대.md` | 10/23 15:52 | 변형 질문을 "최고 순위"로 합치기 · 한국어 외 모두 번역 → **LQ01(중대재해법 기준) 해결, hit@1 72→81%** | 97% |
| `05_답변평가_개선기록.md` | 10/24~26 | **답변 평가** 단계별 개선 (한국어 답변 10 → 30/32, 외국어 48문항 → 41/48), 환각 점검 | – |
| `06_정확성_판정.md` | 10/26 | 교재 양식 평가셋 24문항 정확 · 근거 · 환각 판정 → **정확 19/24 · 근거 17/17 · 환각 0 · 예외 6/6** | – |

새 보고서를 추가할 때: `cp eval/results/<시각>_retrieval.md eval/reports/<번호>_<내용>.md` 후 이 표에 한 줄 추가.
