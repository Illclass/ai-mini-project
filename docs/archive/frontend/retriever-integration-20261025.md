## 남은 문제 — WAV 업로드

사용자 요청에 따라 문제만 기록하고 수정하지 않았다.

- 위치: `voice-service/app/routers/voice_router.py`의 STT 임시 파일 생성 부분.
- WAV 업로드 시 입력 `input.wav`와 변환 출력 `input.wav`가 같은 경로가 된다.
- ffmpeg는 원본을 제자리에서 변환할 수 없어 실패하고 API가 HTTP 500을 반환한다.
- 동일한 1초 무음 파일을 WebM으로 보내면 정상적으로 인식 결과 없음(422)으로 처리된다.
- 담당자 수정안: 입력 확장자와 무관하게 변환 출력 파일명을 `converted.wav` 등 별도 이름으로 지정하고 실제 WAV 파일 회귀 검사를 추가한다.
- 단위 테스트는 파일 변환을 모의 처리하므로 현재 6개 통과만으로 이 오류를 검출하지 못한다.

## 로컬 실행·복구 참고

테스트 전용 서버는 검증 후 종료한다. 직접 실행하려면 Docker Desktop을 켠 뒤 저장소 루트에서 `./dev.sh --voice`, 별도 터미널의 `frontend/`에서 `npm run dev`를 실행한다. 각 터미널의 Ctrl+C로 종료한다.
