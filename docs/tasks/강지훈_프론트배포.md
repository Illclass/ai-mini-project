# 작업 카드 — 강지훈 (프론트엔드·배포)

## 할 일
1. `frontend/` 에 Vue.js 화면 (개발 서버 포트 **5174**)
   - 로그인: Java 인증서버 `http://localhost:8080/api/login` (form 방식, 쿠키 발급)
   - 질문: `http://localhost:8001/rag-query` 에 `credentials: "include"` 로 POST
   - 두 질문 영역(화학물질 안전 / 중대재해 법령), 언어 선택(ko·zh·vi)
   - 화면에 보일 것: 로딩, 오류 안내, 답변, **출처 목록**, `handoff` 면 "담당자 확인" 안내, 401 이면 로그인으로
2. 루트 `docker-compose.yml` (db · auth · rag · web) — Day 3

## 고칠 파일
`frontend/` (새로), `docker-compose.yml` (새로)

## 요청·응답 형식 (바꾸지 말 것)
```json
요청 {"question": "중대재해법의 기준은?", "topic": "serious_accident_law", "product_id": null, "language": "ko"}
응답 {"answer": "...", "sources": [{"doc_id": "L2", "section": "제2조 제2호", "title": "...", "url": "..."}],
      "needs_review": false, "handoff": false, "latency_ms": 1250}
```
- topic: `chemical_safety` | `serious_accident_law` · language: `ko` | `zh` | `vi`
- ⚠ 주소는 `localhost` 로. `127.0.0.1` 로 부르면 쿠키가 안 가서 401.

## 완료 기준
- 로그인 → 질문 → 답변·출처 표시까지 브라우저에서 동작
- 로그아웃 상태에서 질문하면 로그인 화면으로
