# 작업 카드 — 박진근 (LLM 생성)

## 할 일
1. `prompt.py` 프롬프트 다듬기: 근거만 사용, 조문·MSDS 항목 번호 표시, 법률 판단 금지, 쉬운 문장
2. `generator.py`
   - 끝에 붙는 안내 문구(`DISCLAIMER`)를 **요청 언어(ko·zh·vi)로** 바꾸기 (지금은 항상 한국어)
   - `needs_review()` · `needs_handoff()` 규칙 다듬기 (판단 요구 표현, 수치 포함 답)
3. `llm.py` 타임아웃·재시도 확인

## 고칠 파일
`rag-service/rag/prompt.py`, `rag-service/rag/generator.py`, `rag-service/rag/llm.py`

## 완료 기준
- "우리 회사 대표이사가 책임 있나요?" → `handoff: true`, 책임을 단정하지 않음
- 베트남어 질문 → 답변·안내 문구 모두 베트남어
- 문서에 없는 질문 → "찾을 수 없음", LLM 호출 안 함
- 약속 확인 테스트 통과

## AI 에게 붙여 넣을 프롬프트
