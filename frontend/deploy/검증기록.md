# Docker Compose 검증 기록

2026-10-26 · macOS Apple Silicon / Docker ARM64 · Docker 메모리 약 8GB

| 항목 | 결과 |
|---|---|
| 이미지 빌드 | Vue/Nginx, Java 17, RAG, 음성 이미지 빌드 성공 |
| 준비 순서 | DB healthy 후 인증 시작, 인덱스 초기화 완료 후 RAG 시작, API 준비 후 web 시작 |
| 인덱스 | 기존 로컬 law/msds를 별도 볼륨에 복사, 두 영역 모두 ready |
| 인증 | 실제 가입·로그인·쿠키 확인·로그아웃 성공, 미인증 auth/RAG/TTS는 401 |
| 실제 RAG | 황산 보관 질문: 출처 4개·handoff=false / 일반 실내 보관 질문: 출처 1개·handoff=false |
| 실제 음성 | TTS로 생성한 MP3를 WebM으로 변환해 STT 요청 성공, 인식 결과 18자 |
| 프론트·문서 | Nginx를 통한 빌드 화면과 PDF 제공, 브라우저 회원가입·로그인 성공 |
| 데이터 유지 | Compose DB·인증 재시작 후 동일 테스트 계정 로그인 성공 |
| 복구 문제 및 수정 | 최초 Nginx가 이전 컨테이너 IP를 유지해 502 발생. Docker DNS 재조회 적용 후 재시작·로그인 복구 통과 |
| 비밀값 | 기존 env_file 재사용, RAG·음성 이미지 내 .env 없음 확인 |
| 기존 개발 환경 | ai-mini-db와 다른 프로젝트 컨테이너를 중지·삭제하지 않음 |
| 회귀 검사 | 프론트 72개·RAG 876개 통과(12개 제외), Java 인증 Gradle test 성공(캐시), 프론트 컨테이너 빌드 성공 |

관찰된 컨테이너 메모리: RAG 약 1.9GB, 음성 약 0.94GB, 인증 약 0.2GB, DB 약 0.08GB. 초기 모델 로딩·동시 요청에는 추가 여유가 필요합니다.

실제 RAG·TTS는 기존에 재사용 승인을 받은 키로 소량 호출했습니다. 테스트 계정의 비밀번호·토큰과 API 키는 기록하지 않았습니다. 테스트 계정은 별도 Compose DB에 남습니다.

제한: 기존 캐시·인덱스를 활용해 검증했으므로 완전히 빈 환경의 모델 다운로드·전체 재적재 시간은 측정하지 않았습니다. 실제 사용자 마이크 녹음 대신 생성된 WebM으로 API 경로를 검증했습니다. 기존 WAV 500·무음 인식 문제는 수정하지 않았습니다. 외부 서버·HTTPS 배포는 이번 작업 범위에 포함되지 않습니다.
