관찰된 컨테이너 메모리: RAG 약 1.9GB, 음성 약 0.94GB, 인증 약 0.2GB, DB 약 0.08GB. 초기 모델 로딩·동시 요청에는 추가 여유가 필요합니다.

실제 RAG·TTS는 기존에 재사용 승인을 받은 키로 소량 호출했습니다. 테스트 계정의 비밀번호·토큰과 API 키는 기록하지 않았습니다. 테스트 계정은 별도 Compose DB에 남습니다.

제한: 기존 캐시·인덱스를 활용해 검증했으므로 완전히 빈 환경의 모델 다운로드·전체 재적재 시간은 측정하지 않았습니다. 실제 사용자 마이크 녹음 대신 생성된 WebM으로 API 경로를 검증했습니다. 기존 WAV 500·무음 인식 문제는 수정하지 않았습니다. 외부 서버·HTTPS 배포는 이번 작업 범위에 포함되지 않습니다.

## 라우터 및 PDF 원문 추가 확인

- Docker에서 PDF 파일은 200 응답했지만 ES 모듈 워커가 `application/octet-stream`으로 제공되어 렌더링이 실패하는 문제를 재현했습니다. `.mjs`에 JavaScript MIME을 지정해 수정했습니다.
- 배포 smoke 검사에서 워커 MIME 및 빌드된 원문 PDF 27개를 추가 확인합니다.
- Vue Router 경로·인증·뒤로/앞으로 이동 회귀 테스트 8개 추가. 기존 프론트 72개와 합쳐 80개 통과, RAG 876개 통과(12개 제외).
- 실제 브라우저: 법령 질문 주소 직접 진입 시 로그인으로 이동, 로그인 후 원래 질문 영역 복귀, 질문 화면 새로고침, 메인/질문 뒤로가기·앞으로가기, 로그아웃 뒤 과거 경로 접근 차단을 확인했습니다.
- 실제 황산 보호장갑 질문 후 8항 버튼을 눌러 MSDS 6페이지의 8항 제목 위치가 열리고, 1항 선택 시 1페이지로 이동하는 것을 확인했습니다. 대표 법령 책자도 정상 렌더링됐습니다.
